# Historique des versions

Toutes les versions publiées : [page des versions](https://github.com/yacineboulyali/ClasseControl/releases).

## 1.12.0
- Demande de silence : emoji 🤫 + son de notification chez les élèves (message personnalisable, variante sans son)

## 1.11.0
- Annotation de l'écran d'un élève (stylo, surligneur, formes, flèches, couleurs) visible en direct chez l'élève
- Verrouillage du Wi-Fi et du Bluetooth (marche/arrêt, mode avion, changement de réseau)

## 1.10.0
- Mise à jour automatique depuis GitHub (tâche planifiée SYSTEM, toutes les heures)
- Version de chaque poste dans la console, « Mettre à jour les postes », « Vérifier les mises à jour »

## 1.9.1
- Installateur : suppression des jeux préinstallés de Windows pour tous les utilisateurs (et l'image Windows)

## 1.9.0
- Restrictions par élève, mémorisées par poste
- Catégories prêtes : jeux Windows, plateformes de jeux, messageries, réseaux sociaux, vidéo, jeux en ligne
- Jeux du Microsoft Store reconnus et fermés ; désinstallation depuis la console

## 1.8.0
- Blocage du clavier et de la souris (écran visible) ; verrouillage, écran noir et diffusion bloquent aussi les entrées physiques

## 1.7.0
- Contrôle direct d'un poste, panneau des applications ouvertes (écran partagé)
- Son coupé, glisser-déposer des vignettes

## 1.6.0
- Une seule application (`ClasseControle.exe`) pour le professeur et l'élève, avec écran de choix du mode

## 1.5.0
- Couper Internet ; document d'équipe fiabilisé (transformation opérationnelle) ; modèle de document
- Documentation illustrée (captures et GIF) ; publication automatique sur GitHub

## 1.4
- Interface à ruban, barre latérale, vignettes ; icônes vectorielles flat ; zoom des vignettes
- Écran noir, discussion, annonce audio, étoiles, sondages, accès web par modes, lancement rapide, bureau élève

## 1.3
- Installateur prof / élève ; séance avec identification ; ouverture de site ; écran de verrouillage personnalisé
- Présentation de l'écran d'un élève ; équipes avec document partagé et discussion

## 1.2
- Diffusion de l'écran du professeur, restrictions, main levée, présence, journal

## 1.1
- Miniatures en direct, alimentation à distance, sélection groupée
